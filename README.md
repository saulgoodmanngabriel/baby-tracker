# Baby Tracker

A simple, privacy-first baby feeding and diaper tracking PWA.

## Features

- 📊 Visual statistics (feeding count, total milk, diaper changes)
- ⏱️ Timeline view of daily events
- 🍼 Quick record (milk, breastfeeding, diaper)
- 💾 Local storage (works offline)
- 📤 Export data (JSON format)
- 📱 Add to home screen like a native app

## Usage

1. Open on your iPhone/Android
2. Tap "Add to Home Screen"
3. Use like a native app

## Data Storage

All data is stored locally in your browser. No server, no cloud, no tracking.

To backup: tap 📤 button to export JSON.

## Deploy to GitHub Pages

This repository is ready for GitHub Pages deployment:

1. Go to repository Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save and wait for deployment
5. Access at `https://yourusername.github.io/baby-tracker`
